🩵 Cyan Chat Overlay
#####################

This is the best :iconify:`logos:twitch` twitch.tv chat overlay.

.. highlights::

    https://chat.johnnycyan.com/

* Properly supports 7TV, FFZ, BTTV;
* Doesn't have any bugs that other overlays do (e.g. non-working zero-width emotes);
* Supports all the fancy stuff like 7TV paints;
* If an emote was added/removed during the stream - automatically refreshes itself.

And a bunch of fancy commands that you can see in its "Commands" dropdown in that page. 
These commands are normally locked to moderators only.
However, in my stream's chat - if you type ``!chat something`` - 
my bot will repeat its message, essentially still sending your command to Cyan Chat.
