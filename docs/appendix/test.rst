!tag add 
--------

.. rubric:: Syntax

* **Usage:** ``!tag add <tag_name> <tag_content>`` 
* **Aliases:** ``!tag a``, ``!tag create``

.. rubric:: Permissions & Conditions

This command is locked to a moderator role.

.. rubric:: Description

Add a new tag.

.. rubric:: Arguments

* ``<tag_name>`` - Name for the new tag, should be one word (no spaces).
* ``<tag_content>`` - Content for the new tag.

.. rubric:: Example(-s)

* ``!tag add info Some cool info`` - will add a tag under ``<tag_name>`` "info" with ``<tag_content>`` being "Some cool info"
